# axon_quant 0.26.0 Phase 0 准确性加固 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除确定性裂缝(多品种 HashMap 迭代序)、补数据质量门(release 级 OHLC/迟到重复可见化),并建立 golden 指纹与 lint 纪律两道常设护栏;单版本 0.26.0,七笔提交 C0–C7。

**Architecture:** 行为修复只动 `axon-backtest`(排序收集)与 `axon-kernel`/`axon-worker`(校验门/水位线);护栏全部 additive(`RunResult` 补 Serialize、`canonical.rs` 新增、workspace lints)。指纹永远建在稳定语义上:单品种负载先于行为修复,多品种负载锁存修复后语义。

**Tech Stack:** Rust 2024 workspace / clap-nothing 新依赖(零新增外部依赖)/ proptest(已有)/ serde_json(已有)/ mkdocs 文档(zh+en 同步,CI docs-drift 阻塞)。

**Spec:** `docs/superpowers/specs/2026-11-25-axon-quant-0.26.0-accuracy-hardening-design.md`

**与 spec 的实现细化(YAGNI,不改验收标准):**
1. `print_stdout = "deny"` 只有在 clippy 验证零违规后才进首批;若 axon-cli 等合理使用即把它移出首批(记录到 CHANGELOG 约束随 C7 说明)。
2. `#![deny(clippy::unwrap_used)]` 对 kernel 必须 `cfg_attr(not(test), deny(...))`——kernel tests 大量 `.unwrap()`,只锁生产路径。
3. C3 的 EMA 交叉 Host 在 canonical.rs 自算(不依赖 axon-strategy),避免引入跨 crate 依赖。

**提交信息语言:** 英文,`feat:/fix:/test:/chore:/docs:` 前缀。**每笔 commit 前必跑**:`cargo fmt --all` + `cargo clippy --workspace --all-targets --locked -- -D warnings` + `--features python` 变体(仅当触碰绑定层)+ `cargo test --workspace --locked`(AGENTS.md 铁律)。
